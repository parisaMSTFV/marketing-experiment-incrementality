# Security and data policy

This public case study uses data generated entirely by the code in
`src/marketing_incrementality/simulate.py`.

Do not commit:

- real customer, order, campaign, or employee data;
- internal table, schema, server, dashboard, or file names;
- credentials, tokens, connection strings, or environment files;
- non-public thresholds, commercial terms, or company results.

The customer-level synthetic dataset is regenerated locally and excluded from Git.
Only compact aggregate reports and charts are committed.

If a security issue is found, report it privately to the repository owner instead
of opening a public issue with sensitive details.
